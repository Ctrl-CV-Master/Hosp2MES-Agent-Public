## Known Issues

- `BrowserEnv` (Playwright) is a documented extension point only — the public demo runs on `ApiEnv` (REST), so it works without a browser.
- `./mes_demo.db` must be regenerated by the backend on first start (auto-created). Avoid committing it (git-ignored).
